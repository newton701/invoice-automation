# Prompt history (required submission artifact)

The assessment requires a record of every prompt sent to any AI tool, including the current chat. Keep a dated, chronological log here (for example, `prompts/2026-10-27.md`). Include the actual prompt text, tool used, and a brief note describing how the result was used. This README is only a guide, not a complete prompt history. Before submission, add the complete prompts from your chat history and any other AI tools you used.
